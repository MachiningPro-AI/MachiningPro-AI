## 3  B-Rep Backend

**Selected backend**: gmsh 4.15.2 (bundled OpenCASCADE)  
**Decision record**: `docs/architecture/STEP_BREP_BACKEND_DECISION.md`  
**Dependency change**: NONE — gmsh already in `pyproject.toml`

Candidates evaluated:

| Backend | Status | Reason |
|---------|--------|--------|
| gmsh 4.15.2 | **SELECTED** | Already installed; bundled OCC; zero new deps |
| pythonocc-core | Rejected | Not in pyproject.toml; large C++ dep |
| cadquery | Rejected | Heavyweight; install complexity |
| OpenCASCADE (direct) | Rejected | No Python bindings without pythonocc-core |

- Multi-body STEP (body_count > 1) accepted but `stock_fixture_relationship=UNKNOWN_TRANSFORM`.
- GOUGE_VALIDATED=NOT_VERIFIABLE — voxel-to-target comparison not yet implemented.
- Feature recognition: HOLE_CANDIDATE only; no POCKET, SLOT, STEP recognition.
